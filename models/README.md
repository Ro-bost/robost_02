# 실행 모델

`rs02_quadruped/`는 제공받은 2026-09-15 원본 패키지에서 실행에 필요한 URDF,
STL 13개, 질량/관절 요약, MuJoCo 모델, 서기 자세 및 모터 설명을 복사한 것이다.
원본과 동일한 파일 해시는 `manifest.json`에 기록한다. 물리 수치와 메시를 변경하지 않았다.
원본 전체는 로컬 `archive/RS02_4족로봇_최종정리_2026-09-15/`에 보존한다.
MJCF의 원본 Windows meshdir는 보존되어 있고 로더가 실행 시 현재 meshes 경로로 교체한다.
이 자산의 공개 사용권은 제공 자료에서 확정하지 않았으므로 별도 오픈소스 라이선스를 부여하지 않는다.
