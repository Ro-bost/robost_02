# RobStride RS02 (ROBSTRIDE02) 모터 사양 요약

- 출처: RobStride 공식 저장소 `Product Literature/RS02/RS02User Manual260713.pdf`(1.2~1.4절)
- 보조 출처: openelab RS02 기술 가이드
- URDF에 쓴 값은 표 아래에 따로 적었다.

## 1. 정격·전기 특성 (매뉴얼)

| 항목 | 값 |
|---|---|
| 정격 전압 | 48 VDC (동작 24–60 VDC) |
| 정격 토크 (연속) | 6 N·m (100 rpm 시험, 방열판 260×280 mm) |
| 정격 상전류 (피크) | 7 Apk ±10% |
| 최대 토크 | 17 N·m |
| 최대 상전류 (피크) | 23 Apk ±10% |
| 무부하 속도 | 410 rpm ±10% (= 42.9 rad/s, 출력축) |
| 무부하 전류 | 0.5 Arms |
| 토크 상수 (유효값) | 1.22 N·m/Arms |
| 역기전력 | 9.6 Vrms/krpm ±10% |
| 감속비 | 7.75 : 1 |
| 극수 / 상수 / 구동 | 28극 / 3상 / FOC |
| 엔코더 | 14-bit 절대(자기식) × 2 |
| 무게 | 380 g ±3 g (매뉴얼). openelab 가이드와 CAD 모델은 405 g |
| 크기 | 78.5 × 78.5 × 45.5 mm |
| 사용 온도 | −20 ~ 50 °C, 권선 제한 145 °C, 제어보드 최대 145 °C |
| 보호 등급 | IP52 (IP67 옵션) |
| 통신 | CAN (MIT / 위치 / 속도 / 전류 모드) |

- 회전자 관성은 매뉴얼에 없다 → Isaac `armature`는 추정값으로 시작하고 실험으로 맞춘다.

## 2. URDF에 적용한 값

| 조인트 | effort (N·m) | velocity (rad/s) | 비고 |
|---|---|---|---|
| `*_hip_joint` (롤) | 17 | 42.9 | 모터 직결 |
| `*_thigh_joint` (피치) | 17 | 42.9 | 모터 직결 |
| `*_calf_joint` (무릎) | 25.2 | 29.0 | 4절 링크 링크비 1.48(60~130° 최소) 반영, 속도 = 42.9 / 1.48 |

- 연속 토크 6 N·m(무릎 약 8.9 N·m)는 URDF에 들어가지 않는다 → RL 보상이나 토크 제한 설계에 쓴다. 발열은 계획 문서 8-23을 참고한다.
- 질량은 CAD 등가 재질로 모터 1개 405 g이다. 매뉴얼 380 g과 25 g 차이가 나며, 로봇 전체로 −0.3 kg 오차 요인이다.
