# 기존 보고서 색인

현재 사용자 안내는 [docs/user](../user/STRUCTURE.md)에 있다. 아래 문서는 과거 실험 근거이며,
문서 안의 루트 경로와 `python 파일.py` 명령은 정리 이전 형식이다.
현재는 루트에서 PYTHONPATH=src를 설정한 뒤 `python -m 파일명`을 사용한다.

| 자료 | 용도 |
|---|---|
| [계단 개선 실험](RS02_계단_개선_실험.md) | 실패 → 수정 → 선택 후보 및 반복 평가 |
| [RL 실행 기록](RS02_RL_실행_기록.md) | 환경·학습·검증 이력 |
| [동적 보행 계획](RS02_동적보행_계획.md) | 목표 수정과 고정 정책 한계 평가 계획 |
| [동적 보행 발표 설명](RS02_동적보행_발표설명.md) | 현재 PPO 구조의 발표 설명 |
| [기존 계단 실행 안내](RS02_계단_실행방법.md) | 당시 시연 결과·영상 위치 |
| [계단 코드 설명](RS02_계단_코드설명.md) | 모듈·관측·제어 설명 |
| [WALK 검증](WALK_검증_보고서.md) | 이전 Raibert/crawl 결과 |
| [MPC 검증](MPC_트롯_검증_보고서.md) | 이전 MPC 실험 |
| [MuJoCo URDF 안내](MUJOCO_URDF_실행_가이드.md) | 모델 로더/자세 검증 이력 |
| [과거 파일 설명](ROBOST_파일_설명_보고서.md) | 정리 이전의 전체 자료 목록 |
| [과거 보행 발표 대본](보행모델_설계_발표대본.md) | 이전 제어기 발표 자료; 현재 PPO 성능 자료가 아님 |

`evidence/`의 summary.json 두 개는 기존 반복 결과를 바이트 그대로 복사했다.
JSON 안의 절대경로는 실험 당시 위치이며 공개 소스에서 그대로 열리지 않을 수 있다.
전체 평가 상태·영상·가중치는 로컬 `output/`에 보존한다.
