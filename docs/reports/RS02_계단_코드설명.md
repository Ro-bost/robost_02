# RS02 계단 보행 코드 안내

사용자가 실행할 진입점은 `run_rs02_stairs.py`다. `--stairs-cm 15|20`과 `--speed`를 사용한다.
자세 미리보기용 `run_rs02_mujoco.py`는 학습 보행 정책 실행기가 아니다.

## 실행에 사용되는 파일

| 파일 | 역할 |
|---|---|
| `run_rs02_stairs.py` | 높이별 검증 후보 선택, 실시간 GUI 또는 점수/영상 저장 평가 |
| `rs02_rl.py` | 원본 RS02 모델 이식, 토크 제한 PD, 기본 평지 PPO, 공통 실행·측정 |
| `rs02_rl_stairs.py` | 5단 상승/평지/5단 하강,187개 높이 관측, 계단 학습 커리큘럼 |
| `rs02_rl_gait.py` | 1.5Hz 대각선 위상 관측과 접촉 타이밍/스윙 지형 보상, 공통 학습 진입점 |
| `rs02_rl_support.py` | 네 발 아래 지형 대비 몸통 높이,지형 기준 자세,관절/정체/이탈 종료 |
| `rs02_rl_route.py` | 진행 방향/중심선 오차 관측,공개 mjlab heading/world 속도 명령 |
| `rs02_rl_rhythm.py` | 채택 정책 어댑터:접촉 위상 보상 강화,종아리 충격 비용,무릎 목표 여유 |
| `rs02_course_validation.py` | 정책과 독립적인 출구 착지/2초 추가 생존/우회 금지 판정 |
| `evaluate_rs02_stairs_matrix.py` | 체크포인트를 고정해 seed/반복별 새 프로세스로 평가;실패도 보존 |
| `render_rs02_trial.py` | 저장된 물리 상태를1배속 영상으로 렌더링;로봇을 움직이는 제어기가 아님 |
| `plot_rs02_trial.py` | 실제 몸통 궤적·발 접촉·모터 환산 RMS 측정 그림 |
| `audit_rs02_exit.py` | 과거 기록을 새 출구 기준으로 별도 감사;원본 JSON을 수정하지 않음 |
| `test_rs02_*.py`,`test_run_rs02_stairs.py` | 원본 물리/판정/제어 설정/launcher 회귀 테스트 |

`rs02_rl_damped.py`, `rs02_rl_guard.py`는 채택하지 않은 별도 제어 실험이다.
현재 기본 실행에는 전역 PD 감쇠 증가나 예측 관절 제동 필터가 들어가지 않는다.
`third_party/mjlab` 원본 코드는 수정하지 않았다.

## 매 순간의 동작

1. 관측240개를 입력한다:기존 몸통/관절/명령48개 +지형187개 +위상2개 +방향/중심선3개.
2. PPO actor(256→128→128)가50Hz로12개 관절 목표 보정량을 동시에 계산한다.
3. 목표각을 안전 여유 안으로 제한하고,500Hz 물리에서 기존 PD가 토크 상한 안에서 실행한다.
4. 발과 계단의 접촉 힘으로 몸통이 움직이며,다음 실제 상태로 피드백한다.

몸통 이동 강제,외부 지지력,관절 궤적 파일 재생은 없다. 영상의 qpos 재생은 **평가 후 렌더링**에만 쓴다.
학습 중 에피소드 초기화는 있지만,평가에서는 첫 종료를 영구 실패로 기록한다.

## 그대로 둔 것과 튜닝한 것

- 원본 링크 질량/관성,총질량16.940606kg,관절12개,원본 hard range,자기/지형 충돌 유지.
- hip/thigh17Nm,calf25.2Nm 토크 상한. PD는kp60/60/80,kd2.
- armature0.012는 기존 MuJoCo 점검 모델과 같은 값이다. 실물 회전자 관성 보정이 끝났다는 뜻은 아니다.
- 무릎 목표는 hard range보다flexion 쪽0.08rad,extension 쪽0.15rad 안쪽이다.
  목표 제한은 실제 각도 제한을 보장하지 않으므로 실제 관절 초과 종료도 유지한다.
- 학습은 공개 mjlab+RSL-RL PPO를 재사용했다. Go1 사전학습 정책을 그대로 실행한 것은 아니다.
- 정확한 시뮬레이션 상태/높이 지도/전역 방향을 사용한다.실물 센서/추정기로 대체한 검증은 별도다.

## 발표에서 사용할 표현

“PPO 전신 피드백 정책을 RS02에 맞춰 학습했고,15/20cm 코스를 각각6회 반복 완주했다.”
“트롯 위상 조건을 사용하되 실제 계단에서는3발 지지도 있는 혼합 보행이다.”
“종아리 접촉과 모터 정격 대비 RMS 문제 때문에 실물 하드웨어 안전 통과는 아니다.”
