사용자 안내, AI 작업 맥락, 연구 색인을 새로 작성했다. 현재 상태는 STATUS.md,
현재 실행 명령은 RUN.md로 일원화하고 이전 문서에는 보존 보고서 안내를 붙였다.
원본 보고서와 Python 코드는 `archive/reorganization/original_root/`에도 바이트 그대로 보관한다.
첫 이동의 경로/파일 해시는 `archive/reorganization/moves.json`에 있다.

새 경로는 `src/robost_paths.py`에서 관리한다. Python 모듈 이름은 기존 어댑터 import와 호환되게 유지했다.
독립 프로세스 평가 명령은 `python -m ...`로 수정했고 평가 코드 스냅샷에 경로 모듈도 포함했다.
기존 모듈과 데이터의 물리·보상·판정 조건은 변경하지 않았다.

## 용량과 배포

정리 전 전체는 약 9.5GB이며 대부분이 실험 결과다. 결과 원본을 삭제하여 디스크를 줄인 작업은 아니다.
GitHub 소스에는 `output/`, `archive/`, 외부 checkout, 빌드·캐시를 제외한다.
필수 실행 모델 약 24.5MiB를 포함한 소스 묶음과 선택 가중치 2개를 분리했다.
실험·원본 보존을 위해 로컬에는 모델 선별 복사본 약 24.5MiB와 배포 압축만큼 추가 공간을 사용한다.

## 검증

- CPU rs02-mujoco 환경: `make test-core` 10개 통과.
- GPU RL rs02-rl 환경: `make test-rl`에 해당하는 기존 회귀 테스트 21개 통과.
- 원본 URDF 로딩: 19 bodies, 12 joints, 30 geoms, 13 meshes, 질량 16.9406kg 유지.
- Cheetah C++ 라이브러리를 새 build 경로에서 재빌드하고 swing 및 물리 테스트 통과.
- editable 설치와 `rs02-stairs --help` 확인.
- 독립 프로세스 GPU 평가 4초 정상 종료: `output/rl/organization_smoke_20260923/`.
  짧은 경로 점검이므로 코스 미완주가 정상이며 완주 성능 검증으로 계산하지 않는다.
- 기존 외부 저장소 3개의 커밋 고정값과 수정 없음 확인.
- 별도 임시 폴더에 소스 묶음만 풀고 외부 코드를 고정 커밋으로 새로 다운로드한 뒤 `make check test-core` 통과.
  학습 가중치가 없는 소스 배포에서도 기본 정책 설정을 검사하도록 launcher 테스트를 정책 manifest 기준으로 수정했다.
- 문서 상대 링크·Python 문법·모델 해시·배포 파일 목록 검사 통과. 원본 코드/문서 백업과 선별 결과 JSON의 바이트 동일성 확인.
- 배포 압축 안의 모든 파일 SHA-256 및 크기를 manifest와 대조했다. 소스 약 7.7MiB, 가중치 약 5.0MiB로 분리했다.

초기 전체 테스트 실행에서 환경 분리 때문에 RL 환경에 OSQP가 없었다.
CPU 10개와 RL 21개를 각각의 기존 환경에서 실행하여 모두 통과했다. 관련 없는 패키지를 추가 설치하지 않았다.

GitHub 원격 업로드·원격 CI, 새 GPU 환경 전체 설치, 40초×전체 반복 평가, 실물 운용은 이번 정리 범위에서 수행하지 않았다.
